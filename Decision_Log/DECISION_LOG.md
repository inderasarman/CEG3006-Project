|2026-03-25|The team considered whether pedestrian age should be included in the safety logic so that the system can apply stricter warning thresholds for more vulnerable users|No age-based logic; age-group-based logic; fully individualized logic|Safety, fairness, implementation complexity, usefulness of alerts|Age-group-based logic was selected so the system can apply stricter thresholds when an elderly pedestrian is identified, helping provide earlier warnings and encouraging drivers to be more cautious|Used AI to explore whether age-based logic could improve safety thresholds and to identify implementation considerations for vulnerable pedestrians|ALL|
|2026-03-24| The team wanted to explore whether LiDAR data could be used to estimate the weight (or weight class) of the nearest approaching vehicle, to better understand potential impact severity at the crossing|1) Do not estimate weight; only detect distance and speed. 2) Use simple rule‑based classification (e.g. vehicle length/height as proxy for weight class). 3) Train a machine‑learning model using LiDAR features (point cloud density, height profile, length, speed) to estimate vehicle weight class|Technical feasibility, data requirements, model complexity, real‑time performance, benefit to safety logic, explainability| The team decided to treat LiDAR‑based weight estimation as a higher‑level “weight class” feature using a trained model rather than trying to infer exact vehicle mass. A LiDAR‑based classifier can use geometric features and motion information to distinguish between broad categories such as motorcycle, car, and heavy vehicle, which is sufficient for adjusting alert strictness without requiring precise weight values that would be difficult to estimate reliably in real time. This approach keeps the computation manageable, aligns with the available sensor data, and still provides useful input to the safety decision matrix|Used AI to brainstorm possible approaches (no weight, rule‑based, and ML‑based) and to clarify which LiDAR features could realistically support weight‑class estimation for the prototype| All|
